# 员工接入规范

> 这份文档面向需要把 HTML 页面交到平台上的同事。看完五分钟就能完成第一次提交。

---

## 一、为什么要走这个流程

以前大家各自做 HTML，想放哪放哪，结果是：

- 半年后没人记得某个页面在哪，只能挨个部门问
- 页面内容过时了没人更新，管理层看到的还是旧数据
- 不清楚哪些内容能对外，哪些不能，存在外泄风险

平台的目标是**让"交上来"比"自己存着"更省事**。只要走一次流程，之后就是顺手的事。

## 二、准备你的页面

### 2.1 两种形式都支持

**单文件 HTML** —— 样式、脚本、图片全部内联在一个 `.html` 里，最常见。
上传时只会保存这一个文件，所以任何指向其它文件的引用（`src="assets/x.png"`、`<link href="style.css">`）都不会被上传，打开后必然是 404。
**只要页面带独立的图片 / 样式 / 脚本文件，就必须用 ZIP 压缩包。**

**ZIP 压缩包** —— 页面较大，或带独立资源（图片、样式、脚本）时使用。

ZIP 的目录结构要求：

```
你的压缩包/
├── index.html        ← 必须存在，作为入口
├── assets/
│   ├── style.css
│   └── logo.png
└── about.html         ← 可选，包内其他页面
```

三个要点：

1. **根目录必须有 `index.html`**
2. 如果压缩包最外层只有一个文件夹（`我的页面/index.html`），系统会自动帮你拍平；**它里面的资源目录（`assets/`、`images/` 等）会一并保留**，不用手动调整
3. 资源用**相对路径**引用，且必须与包内实际目录同名：HTML 里写 `images/logo.png`，包里就要有 `images/logo.png`

### 2.2 几条硬性要求

| 要求 | 原因 |
|---|---|
| 页面为**纯静态展示** | 平台在沙箱中运行页面，页面不能调用内部接口、不能读写本地存储 |
| 不要在页面里写死账号口令 | 任何拿到页面的人都能看到源码 |
| 不要引入需要登录才能访问的 CDN 资源 | 外网访客打开会白屏 |
| 单文件不超过 100 MB | 压缩包解压后不超过 200 MB、单页不超过 50 MB |
| 不要放可执行文件（.exe / .bat / .sh / .php） | 平台只接受网页相关文件类型 |

## 三、提交步骤

1. 打开内网门户 → 右上角「**登录**」→ 用公司邮箱登录
2. 点左侧导航「**上传页面**」
3. 选择文件，填写：
   - **页面标题**：写清楚这是什么，例如「2026 Q1 销售战报」
   - **页面描述**：一句话说明，方便别人搜到
   - **业务分类**：从已有分类里选
   - **可见性**：见下节，**必须选择，没有默认值**
   - **标签**：便于搜索，可留空
4. 点「上传并保存为草稿」
5. 打开左侧导航「**我的页面**」，找到刚上传的页面，点「**提交审核**」

## 三之二、你会看到哪些功能

平台只有两种身份，导航内容不同：

| 导航模块 | 员工 | 管理员 |
|---|---|---|
| 页面门户 | ✅ | ✅ |
| 上传页面 | ✅ | ✅ |
| 我的页面 | ✅ | ✅ |
| 页面管理 | ❌ | ✅ |
| 审核队列 | ❌ | ✅ |
| 使用统计 | ❌ | ✅ |
| 审计日志 | ❌ | ✅ |
| 基础配置 | ❌ | ✅ |

**你能做的**：上传页面、上传新版本、提交审核、查看自己页面的浏览量和版本历史。

**需要找管理员做的**：修改页面标题/描述/分类/标签、修改可见性、下线、版本回滚、彻底删除。

> 页面详情页右上角会标注「只读视图」，提醒你哪些操作受限。

## 四、可见性怎么选（最重要）

这一步**没有默认值**，必须你自己判断。选错可能导致内容外泄。

| 选项 | 什么时候选 | 谁能访问 |
|---|---|---|
| **外网公开** | 内容可以给外部客户、合作方看，或已在其他渠道公开 | 任何人，无需登录 |
| **仅内网全员** | 内容涉及内部经营数据、未公开的财务/人事信息 | 全体登录员工（含出差 VPN） |
| **指定部门可见** | 内容只与特定部门相关，且含薪酬、编制、绩效等敏感信息 | 所选部门的登录员工 |

判断口诀：

> **这张表拿到竞争对手手里会不会吃亏？** 会，就不能选「外网公开」。

常见误判：

- ❌ 「我们公司不方便对外」→ 选「外网公开」✗ **应该选仅内网全员**
- ❌ 「反正大家都看得到」→ 选「外网公开」✗ 内部可见 ≠ 外网可见
- ❌ 「含客户名单」→ 选「外网公开」✗ **应该选仅内网全员**

## 五、审核

提交后进入审核队列，由审核员或部门负责人处理：

- **通过** → 页面立即发布，外网入口同步生效
- **驳回** → 会收到驳回意见，按意见修改后重新提交

审核主要看三件事：

1. 可见性是否符合内容敏感度
2. 页面里有没有账号、口令、客户名单等不该公开的信息
3. 内容是否是公司正式对外的版本（还是个人草稿）

⚠️ 驳回后不要直接改完就以为生效了，**必须重新提交审核**。同样，上传新版本会让页面回到草稿状态，需要重新走审核。

## 七、页面发布后的维护

### 更新内容

详情页 → 「编辑信息」旁边上传新版本 → 填写版本说明 → **提交审核**。

每次上传都会保留为一个版本，随时可以回滚到历史版本（回滚由管理员操作）。

### 申请下线

> 你自己创建的页面，如果内容过期了、不再需要对外展示了，走「**申请下线**」：

**入口**：我的页面 / 页面详情 → 「申请下线」

**流程**：

```
你填原因并提交
      ↓
页面【继续在线】，管理员在「审核队列 → 下线申请」看到
      ↓
   ┌──┴──┐
 批准   驳回
   │      │
真正下线  页面继续在线
从所有   你会看到管理员的处理意见
入口移除  可修改原因后重新申请
```

**几个要点**：

- 提交申请时必须填原因（至少 5 个字），管理员据此判断
- 申请期间**可以随时撤回**，撤回后页面继续在线
- 被驳回后页面**不受影响**，可以根据管理员的意见修改原因重新申请
- 申请不会过期，一直挂着直到你撤回或管理员处理

> ⚠️ **提交申请后页面不会立即消失**，要等管理员批准。
> 如果页面内容**需要立即下线**（比如发现了敏感信息），请直接联系管理员强制下线，不要等流程。

**管理员**在审核队列里能直接看到你的申请原因、浏览量、当前状态。

### 删除页面

如果这个页面你彻底不要了（传错了、草稿废弃了、审核被驳回放弃了），走「**删除**」。

**入口**：我的页面 / 页面详情 → 「删除」

> **只有草稿和被驳回的页面才有「删除」按钮。** 已发布、待审核的页面没有删除按钮。

```
删除 → 进入回收站
     → 30 天后自动彻底删除
```

- 回收站里的页面**保留 30 天**，期间你可以在「我的页面 → 回收站」里**恢复**
- 30 天到期后平台自动彻底清除记录和文件，**不可恢复**
- 只有管理员可以执行「彻底删除」，也就是不等 30 天立刻清掉

**已发布的页面想下线怎么办**：

```
已发布 → 申请下线 → 管理员批准 → 回到草稿 → 这时才可以删除
```

管理员也可以直接点「下线」立即生效，不用等审批。

**删除 vs 下线 怎么选**：

| | 下线 | 删除 |
|---|---|---|
| 什么时候能操作 | 已发布的页面 | 只有草稿、审核驳回的页面 |
| 页面还会再用吗 | **会**，只是暂时不展示 | **不会** |
| 之后想重新上架 | 提交审核即可恢复上线 | 30 天内可恢复，恢复后仍需重新提交审核 |
| 数据保留 | 永久 | 30 天后自动清除 |

> 已经发布过的页面**没有删除按钮**，这是有意设计的：不能让任何人绕过管理员审批直接下线。需要下线就申请，管理员批准后再删。

### 直接下线（管理员）

详情页 → 「下线」。页面立刻从门户移除、外网立即 404。需要时重新提交审核即可恢复。

## 八、常见问题

**Q：为什么我上传的页面在同事那看不到？**
A：检查三件事 —— ① 页面是否还是草稿/待审核状态（需要审核通过）；② 可见性是否设成了「指定部门可见」而对方不在该部门；③ 对方是否在内网入口访问（外网入口只看得到公开页面）。

**Q：为什么我在外网入口看不到自己的内网页面？**
A：这是预期行为。外网入口按设计只展示「外网公开」的页面。

**Q：我的页面里有图表需要读接口数据，能放吗？**
A：不能。平台在 CSP 沙箱中运行页面：`connect-src 'none'`，页面无法发起 fetch/XHR/WebSocket 等任何数据请求。页面可以引用外部静态资源（CDN 脚本、字体、图片、视频），但无法向后端读写数据。需要动态数据的页面请提出来，我们再评估方案。

**Q：单文件 HTML 上传后图片不显示？**
A：单文件上传只保存那一个 `.html`，图片文件没有一起上传，浏览器请求图片时必然 404。两种解决办法：① 把图片转成 base64 内联（`<img src="data:image/png;base64,...">`）；② 把 HTML 和图片文件夹一起打成 ZIP 重新上传（推荐）。

**Q：ZIP 包解压后页面显示不正常？**
A：通常是资源路径问题。确认 HTML 里用的是相对路径，且与包内目录同名：HTML 写 `images/logo.png`，包里就要有 `images/logo.png`；不要用从本机复制的绝对路径（`D:/work/xxx/style.css`），也不要用以 `/` 开头的根路径。

**Q：打开页面后地址里多了一段 `_a/...`，是什么？**
A：那是平台给这个页面的图片/字体/视频签发的资源通行证（7 天有效）。页面本身仍然要登录、并且有权限才能打开，把地址转给同事不会越权——对方没权限时看到的还是 404。从门户重新点开会自动换新地址。

**Q：能放几个页面在一个包里？**
A：可以。包里可以有 `index.html`、`about.html` 等多个页面，平台会一起发布。

**Q：我把自己电脑上的页面删了，平台上的还在吗？**
A：在。平台有完整副本，且保留了所有历史版本。
